# PT Samudera Utama Lestari — Company Profile

Website company profile statis untuk GitHub Pages.

## File
- `index.html` — struktur halaman
- `style.css` — desain responsif
- `script.js` — menu mobile dan tahun footer

## Deploy ke GitHub Pages
1. Upload ketiga file ke repository.
2. Pastikan `index.html` berada di root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch utama (misalnya `main`) dan folder `/root`.
6. Simpan dan tunggu proses deployment selesai.

## Catatan
Konten website disusun berdasarkan company profile PT. Samudera Utama Lestari yang diberikan. Informasi kontak resmi tidak tersedia pada materi sumber, sehingga email pada tombol kontak masih berupa placeholder dan harus diganti sebelum publikasi.
